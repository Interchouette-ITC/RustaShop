# Apps (UI surfaces)

HTTP UIs that speak the Commerce API. Not Rust crates.

| Path | Make | Role |
| --- | --- | --- |
| `shop-angular/` | `make shop-angular` | Track A customer shop (Angular SPA) |
| `shop-leptos-rangular/` | `make shop-leptos-rangular` | Track B customer shop (when scaffolded) |

Naming lock: folder name = Make target (`shop-<stack>`). Backend lives under `crates/`.
